Pattern 1 — Définitions

Cours : Les Variables en Algorithmique

I. Définition d'une variable
Une variable est une case mémoire qui permet de stocker une valeur.
Le terme "variable" désigne un emplacement nommé dans la mémoire de l'ordinateur.
On appelle déclaration l'action d'indiquer au programme qu'on a besoin d'une variable.
La notion de type définit la nature des données qu'une variable peut contenir.
Un entier est un nombre sans virgule, positif ou négatif.
Une chaîne de caractères est une suite de lettres, chiffres ou symboles.
Un booléen représente une valeur vraie ou fausse.

II. Déclaration d'une variable
La déclaration se définit comme l'opération qui réserve de l'espace mémoire.
On entend par affectation l'action d'assigner une valeur à une variable.
Le concept d'initialisation correspond à la première affectation d'une variable.

Pattern 2 — Causes / Origines

Marqueurs déclencheurs : est dû à, résulte de, s'explique par, provient de, est provoqué par, a pour cause, découle de, en raison de

Cours : Les Erreurs en Programmation

I. Causes des erreurs de compilation
Une erreur de compilation est due à une mauvaise syntaxe dans le code source.
Le message d'erreur résulte de la vérification du code par le compilateur.
L'échec du programme s'explique par l'absence d'un point-virgule en fin d'instruction.
Une erreur de type provient d'une affectation incompatible entre deux variables.
Le blocage du programme est provoqué par une boucle infinie.

II. Causes des erreurs d'exécution
Un dépassement de tableau découle d'un accès à un indice hors limites.
La division par zéro a pour cause l'absence de vérification préalable du diviseur.
Le programme plante en raison d'une variable non initialisée.
L'erreur mémoire trouve ses origines dans une mauvaise gestion des pointeurs.

Cours : Gestion de la Mémoire

I. Conséquences d'une mauvaise gestion mémoire
Un mauvais usage des pointeurs provoque des erreurs difficiles à détecter.
La fuite mémoire entraîne un ralentissement progressif du système.
L'absence de libération mémoire conduit à l'épuisement des ressources disponibles.
Un débordement de tampon aboutit à des comportements imprévisibles du programme.
La corruption de données engendre des résultats de calcul erronés.

II. Effets d'une bonne gestion mémoire
Une allocation correcte génère des programmes plus stables et fiables.
La libération systématique des ressources mène à une meilleure performance.
Une gestion rigoureuse se traduit par une durée de vie accrue de l'application.
Le contrôle des accès mémoire a pour conséquence la réduction des failles de sécurité.

Pattern 4 — Étapes / Processus / Phases

Marqueurs déclencheurs : se déroule en, comporte N étapes, comprend N phases, d'abord, ensuite, puis, enfin, finalement

Cours : La Compilation d'un Programme

I. Les étapes de la compilation
La compilation d'un programme se déroule en quatre grandes étapes.
Le processus comprend quatre phases successives et obligatoires.

D'abord, le préprocesseur traite les directives et inclut les fichiers d'en-tête.
Ensuite, l'analyse lexicale découpe le code source en unités syntaxiques appelées tokens.
Puis, l'analyse sémantique vérifie la cohérence des types et des opérations.
Enfin, la génération de code produit le fichier exécutable final.

II. Les étapes du débogage
Le débogage d'un programme comporte trois phases essentielles.
Premièrement, on reproduit l'erreur de façon systématique.
Deuxièmement, on isole la portion de code responsable.
Troisièmement, on corrige et on vérifie que le problème est résolu.
Finalement, on teste l'ensemble du programme pour détecter les régressions.

Pattern 6 — Caractéristiques / Propriétés

Marqueurs déclencheurs : se caractérise par, possède, présente, a pour propriété, dispose de, est doté de, se distingue par

Cours : Les Structures de Données

I. Caractéristiques d'un tableau
Un tableau se caractérise par une taille fixe définie à la déclaration.
Il possède des éléments de même type stockés de façon contiguë en mémoire.
Un tableau présente un accès direct à chaque élément par son indice.
Il dispose d'une indexation qui commence à 0 en langage C et Python.
Il se distingue par sa rapidité d'accès en temps constant O(1).

II. Caractéristiques d'une liste chaînée
Une liste chaînée est dotée d'une taille dynamique qui évolue à l'exécution.
Elle se caractérise par des éléments appelés nœuds reliés par des pointeurs.
Elle présente un accès séquentiel aux éléments, ce qui la rend plus lente que le tableau.
Elle a pour propriété principale la facilité d'insertion et de suppression en début de liste.

Cours : Les Fonctions en Programmation

I. Rôle des fonctions
Une fonction sert à regrouper un ensemble d'instructions en un bloc réutilisable.
Elle permet de décomposer un problème complexe en sous-problèmes indépendants.
La fonction principale joue le rôle de point d'entrée du programme.
Un paramètre sert à transmettre des données à une fonction.
La valeur de retour permet de renvoyer un résultat au programme appelant.

II. Utilité des procédures
Une procédure est utilisée pour effectuer une action sans retourner de valeur.
Elle contribue à la lisibilité du code en isolant les traitements.
Le passage par valeur vise à protéger la variable originale contre toute modification.
Le passage par référence permet à la fonction de modifier la variable de l'appelant.

Cours : Les Types de Données

I. Exemples de types primitifs
Il existe plusieurs types de données primitifs, par exemple les entiers, les réels et les caractères.
Les langages de programmation modernes incluent des types tels que int, float, char et bool.
On peut citer comme exemples de types numériques : int (entier), double (réel double précision), long (entier long).
Les opérateurs arithmétiques, notamment l'addition, la soustraction et la multiplication, s'appliquent aux nombres.
C'est le cas de l'opérateur modulo (%) qui retourne le reste d'une division entière.

II. Exemples de structures complexes
Les structures de données complexes incluent les tableaux, les listes, les piles et les files.
Par exemple, une pile fonctionne sur le principe du dernier entré, premier sorti (LIFO).
Citons comme illustration d'une file : la file d'attente à une caisse de supermarché.
Les langages orientés objet, comme par exemple Java, C++ et Python, utilisent des classes.

Cours : Histoire de l'Informatique

I. Les grandes dates de l'informatique
En 1936, Alan Turing a proposé le modèle théorique de la machine universelle.
En 1945, John von Neumann a défini l'architecture des ordinateurs modernes.
Le premier ordinateur électronique, l'ENIAC, a été mis en service en 1946.
En 1958, Jack Kilby a inventé le circuit intégré, révolutionnant l'électronique.
Le premier microprocesseur commercial, l'Intel 4004, est apparu en 1971.

II. L'essor d'Internet
En 1969, le réseau ARPANET a été créé, ancêtre d'Internet.
En 1991, Tim Berners-Lee a lancé le World Wide Web lors d'une expérience au CERN.
Le navigateur Mosaic a été publié en 1993, popularisant l'accès au Web.
En 2004, le réseau social Facebook a été fondé par Mark Zuckerberg.
En 2008, le projet Bitcoin a été publié et a débuté une révolution financière numérique.

Pattern 10 — Avantages / Inconvénients

Marqueurs déclencheurs : l'avantage est, le point fort, l'atout, l'inconvénient, le point faible, la limite, cependant, néanmoins, en revanche

Cours : Comparaison des Langages de Programmation

I. Le langage Python
L'avantage principal de Python est sa syntaxe simple et lisible.
Le point fort de ce langage réside dans sa large bibliothèque de modules.
L'atout de Python pour les débutants est l'absence de déclaration de types.
Cependant, Python est plus lent que les langages compilés comme C ou C++.
L'inconvénient majeur de Python est sa consommation mémoire élevée.
En revanche, il est idéal pour le prototypage rapide et la data science.

II. Le langage C
Le point fort du langage C est son exécution très rapide et son contrôle fin de la mémoire.
L'avantage du C réside dans sa portabilité sur tous les systèmes d'exploitation.
Néanmoins, le point faible du C est la gestion manuelle de la mémoire, source d'erreurs.
La limite du C est l'absence de structures objet natives comme en Java ou Python.
Toutefois, il reste le choix de référence pour les systèmes embarqués et les noyaux d'OS.
