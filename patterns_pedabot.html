PédaBot — Les 40 Patterns de Détection

Liste complète des patterns utilisés par le moteur pour analyser un cours et générer des questions.

GROUPE 1 — PATTERNS TEXTUELS CLASSIQUES (1 à 25)

Pattern 1 — Définitions

Question générée : Qu'est-ce que [mot-clé] ?

Type A — Mot-clé AVANT le marqueur :

  • est un / est une / est le / est la
  • est défini(e) comme
  • est appelé(e)
  • est considéré(e) comme
  • est connu(e) sous le nom de
  • est aussi appelé(e) / connu(e) comme
  • est un type / une forme / une sorte / une catégorie de
  • est également / aussi un(e)
  • est utilisé(e) pour
  • est employé(e) pour
  • représente / désigne / constitue / signifie / caractérise
  • correspond à / consiste à / consiste en
  • se définit comme / se caractérise par / se compose de
  • se traduit par / se distingue par
  • fait référence à / renvoie à / s'apparente à
  • permet de / sert à
  • a pour rôle / but / objectif / fonction / mission
  • vise à / peut être défini(e) comme
  • porte le nom de

Type B — Mot-clé APRÈS le marqueur :

  • On appelle / On définit / On nomme / On entend par
  • On désigne par / On note / On parle de
  • On utilise le terme
  • Le terme / La notion de / Le concept de / Le mot

Titres déclencheurs : définitions, concepts, notions, vocabulaire, terminologie, glossaire, rappels, généralités, introduction, pré-requis, présentation

Pattern 2 — Causes / Origines

Question générée : Quelles sont les causes de [mot-clé] ?

  • a été / est causé(e) par
  • est dû / due à
  • résulte de
  • s'explique par
  • provient de
  • est provoqué(e) par
  • trouve son/ses origine(s) dans
  • est lié(e) à
  • a pour cause / origine / source
  • est engendré(e) / occasionné(e) par
  • découle de
  • tire son/ses origine(s) de
  • en raison de

Titres déclencheurs : causes, origines, facteurs, raisons, sources, pourquoi

Pattern 3 — Conséquences / Effets

Question générée : Quelles sont les conséquences de [mot-clé] ?

  • entraîne / provoque
  • conduit à / aboutit à / mène à
  • a pour effet / conséquence / résultat / impact
  • engendre / génère / produit / cause / occasionne
  • peut / risque de entraîner / provoquer / causer
  • se traduit par
  • a des effets / impacts / conséquences
  • est à l'origine / responsable de

Titres déclencheurs : conséquences, effets, impacts, résultats, répercussions, implications

Pattern 4 — Étapes / Processus / Phases

Question générée : Quelles sont les étapes de [mot-clé] ?

  • se déroule en
  • comporte plusieurs / N étapes / phases
  • comprend plusieurs / N étapes / phases
  • se compose de plusieurs / N étapes / phases
  • passe par plusieurs / N étapes / phases
  • suit plusieurs / N étapes / phases

Séquenceurs déclencheurs : d'abord, premièrement, en premier lieu, ensuite, deuxièmement, puis, troisièmement, après, enfin, finalement, pour finir, étape N, phase N

Titres déclencheurs : étapes, processus, phases, déroulement, procédure, mécanisme, cycle, méthode

Pattern 5 — (Réservé / Intégré au Pattern 1)

Ce slot est fusionné avec le Pattern 1 (Définitions) dans le moteur actuel.

Question générée : Quelles sont les caractéristiques de [mot-clé] ?

  • possède / présente les / des / plusieurs

  • comporte / dispose de
  • est doté(e) de / se distingue par
  • a les / des / plusieurs caractéristiques / propriétés / traits

Pattern 7 — Fonctions / Rôles

Question générée : À quoi sert [mot-clé] ?

  • sert à / permet de
  • a pour fonction / rôle / but / mission / objectif
  • joue le / un rôle de
  • assure / vise à
  • est utilisé(e) pour / est destiné(e) à
  • contribue à / a pour vocation de
  • est chargé(e) de / remplit la / une fonction

Pattern 8 — Exemples / Illustrations

Question générée : Citez des exemples de [mot-clé].

  • par exemple / comme (par exemple)
  • tels que / notamment
  • c'est le cas de
  • on peut citer / est illustré(e) par
  • à l'image de / incluent
  • parmi les / eux / elles / citons

Pattern 9 — Dates / Événements Historiques

Question générée : En quelle année [mot-clé] a-t-il eu lieu ?

  • en [AAAA] (année sur 4 chiffres)
  • le [JJ mois AAAA]
  • au [Xème siècle]
  • a eu lieu / s'est produit / a débuté / commencé en / le
  • lors / pendant / au cours de
  • à l'époque de / date de

Pattern 10 — Avantages / Inconvénients

Question générée : Citez un avantage et un inconvénient de [mot-clé] ? / Quels sont les avantages ? / Quelles sont les limites ?

  • l'avantage est / de
  • le point fort / l'atout / le bénéfice
  • l'intérêt est / de
  • le risque est / de
  • l'inconvénient / le point faible
  • la limite est / de
  • le (dés)avantage
  • cependant / néanmoins / toutefois / en revanche / mais

Pattern 11 — Classifications / Typologies

Question générée : Quels sont les différents types de [mot-clé] ?

  • il existe N / plusieurs types / catégories
  • on distingue / se divise en
  • se répartit en / peut être classé(e) en
  • on recense

Pattern 12 — Conditions / Critères

Question générée : Quelles sont les conditions pour [mot-clé] ?

  • à condition(s) que / de
  • nécessite / requiert / implique / suppose
  • il faut que / un / une / des
  • est nécessaire

Pattern 13 — Acteurs / Auteurs

Question générée : Qui a découvert / proposé [concept] ?

  • selon [Nom Prénom]
  • d'après [Nom Prénom]
  • [Nom Prénom] a dit / écrit / proposé / découvert
  • théorie de [Nom Prénom]
  • travaux de [Nom Prénom]
  • découverte par [Nom Prénom]

Pattern 14 — Formules / Théorèmes

Question générée : Quelle est la formule / règle de [mot-clé] ?

  • se calcule par / s'exprime par
  • la formule est
  • selon la loi de / le théorème stipule
  • la relation est / est donné(e) par

Pattern 15 — Chiffres / Statistiques

Question générée : Quel chiffre / pourcentage correspond à [mot-clé] ?

  • représente N% / pourcents
  • atteint N / mesure N / compte N

Pattern 16 — Localisation

Question générée : Où se situe [mot-clé] ?

  • se situe / se trouve
  • est localisé(e)
  • dans le / au nord / sud / est / ouest de
  • s'étend sur

Pattern 17 — Composition / Structure

Question générée : De quoi est composé(e) [mot-clé] ?

  • est composé(e) de / comprend / contient
  • se compose de / est constitué(e) de
  • inclut / regroupe / est formé(e) de

Pattern 18 — Synonymes

Question générée : Quels sont les synonymes / autres termes pour [mot-clé] ?

  • aussi appelé(e) / également nommé(e)
  • autrement dit / c'est-à-dire
  • alias / synonyme de

Pattern 19 — Exceptions

Question générée : Quelle est l'exception concernant [mot-clé] ?

  • sauf / excepté / hormis
  • à l'exception de
  • attention / ne s'applique pas à
  • cas particulier / il faut noter que

Pattern 20 — Objectifs / Finalités

Question générée : Quel est l'objectif de [mot-clé] ?

  • a pour objectif / vise à
  • dans le but de / afin de
  • l'enjeu est de / cherche à

Pattern 21 — Structure / Syntaxe

Question générée : Quelle est la structure de la syntaxe de [mot-clé] ?

  • se présente comme suit
  • la structure de / la syntaxe (générale) de
  • s'écrit / se déclare / se formule

Pattern 22 — Abréviations / Significations

Question générée : Que signifie l'acronyme [mot-clé] ?

  • ACRONYME (développé entre parenthèses)
  • signifie / veut dire
  • est l'abréviation de / est l'acronyme de

Pattern 23 — Tableaux de Formats (C / printf)

Question générée : Quel format utilise-t-on pour afficher/lire un(e) [type] ?

  • %d, %f, %s, %c, %lf, %i … (spécificateurs de format C)
  • associés à leur type de donnée dans un tableau ou liste

Pattern 24 — Notes / Remarques

Question générée : Quelle information importante (NB/Attention) concerne [mot-clé] ?

  • NB / N.B : …
  • Remarque : …
  • Attention : …
  • Important : …
  • À noter : …

Pattern 25 — Traductions Algo ↔ Code

Question générée : Comment traduit-on [instruction] en langage code ?

  • ÉCRIRE / AFFICHER ↔ printf / console.log / print
  • LIRE / SAISIR ↔ scanf / input / prompt / cin
  • Affectation ← ↔ =
  • RACINE / sqrt ↔ √

GROUPE 2 — PATTERNS SYNTAXE CODE (26 à 31)

Priorité maximale : ces patterns priment sur tous les autres.

Pattern 26 — Boucle POUR / for

Question générée : Écrire un algorithme utilisant une boucle POUR.

  • POUR variable DE ... À ... FAIRE
  • FIN POUR
  • for variable in range()
  • for (let/int/var variable = ...)

Titres déclencheurs : boucle pour, boucle for, répétition fixe, compteur, nombre de fois

Pattern 27 — Boucle TANT QUE / while

Question générée : Écrire un algorithme utilisant une boucle TANT QUE.

  • TANT QUE ... FAIRE
  • FIN TANT QUE
  • while condition:
  • while (condition) {

Titres déclencheurs : tant que, while, boucle condition, répétition condition

Pattern 28 — Boucle RÉPÉTER JUSQU'À / do-while

Question générée : Écrire un algorithme utilisant une boucle RÉPÉTER JUSQU'À.

  • RÉPÉTER
  • JUSQU'À
  • do {
  • } while (

Titres déclencheurs : répéter, jusqu'à, do-while, post-condition, saisie valide

Pattern 29 — Structure SI / SINON / if-else

Question générée : Écrire un algorithme utilisant une alternative SI/SINON.

  • SI ... ALORS
  • SINON SI / FIN SI
  • if condition:
  • elif / if (condition) { / else if (

Titres déclencheurs : alternative, si sinon, if else, structure conditionnelle, prise de décision

Pattern 30 — Fonction / Procédure

Question générée : Écrire et appeler une fonction.

  • FONCTION nom()
  • PROCÉDURE nom()
  • RETOURNER
  • def nom():
  • function nom() {

Titres déclencheurs : fonction, procédure, sous-programme, def, modularité, retourner

Pattern 31 — Tableau / Liste / Array

Question générée : Écrire un algorithme utilisant un tableau.

  • TABLEAU[
  • variable[i] / variable[0..N]
  • [] * N (Python)
  • .append() / .push() / new Array()

Titres déclencheurs : tableau, array, liste, indice, index, parcours de

GROUPE 3 — PATTERNS ANALYSE / COMPARAISON / RÈGLES (32 à 40)

Priorité 2 : après syntaxe, avant patterns textuels classiques.

Pattern 32 — Comparaison

Question générée : Comparez les deux éléments mentionnés.

  • contrairement à / à l'opposé de
  • tandis que / alors que
  • par opposition à / en revanche
  • différence entre / comparé à / par rapport à
  • vs / versus

Pattern 33 — Erreur / Piège

Question générée : Identifiez et corrigez l'erreur décrite.

  • erreur courante / fréquente / typique / classique / à éviter
  • piège fréquent / courant / classique
  • attention à ne pas
  • ne pas confondre
  • faute courante / fréquente / classique
  • risque d'erreur

Pattern 34 — Trace d'exécution

Question générée : Complétez le tableau de trace.

  • tableau de trace / valeurs / suivi
  • trace d'exécution
  • déroulement pas à pas
  • valeurs successives
  • à l'itération N / après exécution
  • état du programme

Pattern 35 — Entrée / Sortie

Question générée : Identifiez les entrées et sorties.

  • prend en entrée / retourne en sortie
  • retourne une valeur / le résultat
  • données d'entrée / valeur / résultat de retour
  • paramètres d'entrée
  • entrée : / sortie :

Pattern 36 — Préconditions / Postconditions

Question générée : Énoncez les préconditions et postconditions.

  • précondition / postcondition
  • à condition que / sous réserve que
  • garantit que / assure que
  • contrat de / d'

Pattern 37 — Conversion de Langage

Question générée : Traduisez dans l'autre langage.

  • équivalent en Python / JavaScript / algorithmique
  • s'écrit en Python
  • se traduit en JavaScript / Python
  • correspond en Python / JavaScript
  • la même chose en Python / JavaScript
  • Présence simultanée de code algo + Python ou algo + JS

Pattern 38 — Complexité Algorithmique

Question générée : Analysez la complexité et proposez une amélioration.

  • complexité en temps / espace / temporelle / spatiale / algorithmique
  • O(n) / O(n²) / O(log n) / O(1) / O(n log n)
  • plus efficace / optimal / rapide que
  • moins efficace
  • coût en mémoire / computationnel / d'exécution
  • nombre d'opérations / algorithme optimal

Pattern 39 — Règle Absolue

Question générée : Énoncez la règle et donnez un contre-exemple.

  • il faut toujours
  • on ne doit jamais / pas
  • ne jamais
  • principe fondamental
  • règle d'or / de base / fondamentale
  • toujours vérifier / s'assurer / initialiser
  • interdit de

Pattern 40 — Schéma / Organigramme / Diagramme

Question générée : Décrivez ou reproduisez le schéma.

  • le / un schéma montre / représente / illustre
  • comme le montre la figure / le diagramme / le schéma
  • représenté par le / un diagramme / schéma
  • la figure / le diagramme ci-dessous / suivant
  • représentation graphique
  • organigramme
  • diagramme de / d' / des
