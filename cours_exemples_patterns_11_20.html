Pattern 11 — Classifications / Typologies

Marqueurs : il existe N types, on distingue, se divise en, se répartit en, peut être classé en, on recense

Cours : Les Types de Mémoire

I. Classification des mémoires
Il existe deux grandes catégories de mémoire dans un ordinateur.
On distingue la mémoire volatile et la mémoire non volatile.
La mémoire se divise en mémoire centrale et mémoire de masse.
On recense plusieurs types de mémoire RAM : SRAM, DRAM, SDRAM et DDR.
La mémoire peut être classée en mémoire vive et mémoire morte.

II. Types de stockage
Le stockage de données se répartit en stockage local et stockage en réseau.
Il existe trois types de disques de stockage : magnétique, optique et à semi-conducteurs.
On distingue le stockage primaire (RAM), secondaire (disque dur) et tertiaire (sauvegarde).

Pattern 12 — Conditions / Critères

Marqueurs : à condition que, nécessite, requiert, implique, suppose, il faut que, est nécessaire

Cours : Les Conditions d'Exécution d'un Programme

I. Conditions de compilation
La compilation nécessite que le code source soit syntaxiquement correct.
L'exécution requiert que toutes les dépendances soient installées sur le système.
Un programme compilé implique la présence du compilateur adapté au langage.
La portabilité suppose que le code soit écrit sans dépendance matérielle spécifique.

II. Conditions d'une boucle valide
Pour qu'une boucle TANT QUE fonctionne, il faut que la condition soit modifiée à chaque itération.
Une boucle correcte nécessite une condition d'arrêt clairement définie.
Il est nécessaire d'initialiser toutes les variables avant d'entrer dans la boucle.
À condition que le compteur soit correctement incrémenté, la boucle POUR se termine toujours.

Pattern 13 — Acteurs / Auteurs

Marqueurs : selon [Nom], d'après [Nom], [Nom] a proposé, théorie de [Nom], travaux de [Nom], découverte par [Nom]

Cours : Fondements de l'Algorithmique

I. Les pionniers de l'informatique
Selon Alan Turing, tout problème calculable peut être résolu par une machine abstraite.
D'après John von Neumann, un ordinateur doit séparer les données du programme.
Donald Knuth a écrit le livre fondateur de l'algorithmique moderne en 1968.
La théorie de la complexité algorithmique a été développée par Cook et Karp.
Les travaux de Dijkstra ont conduit à l'algorithme du plus court chemin en 1959.

II. Contributions majeures
La notation O grand a été introduite par Paul Bachmann pour analyser les algorithmes.
Le tri rapide a été découvert par Tony Hoare en 1960.
D'après Edsger Dijkstra, le goto est néfaste pour la lisibilité du code.
Selon Niklaus Wirth, un algorithme est la somme de structures de données et de programmes.

Pattern 14 — Formules / Théorèmes

Marqueurs : se calcule par, s'exprime par, la formule est, selon la loi de, le théorème stipule, est donné par

Cours : Complexité Algorithmique

I. Formules de complexité
La complexité temporelle d'un algorithme se calcule par le nombre d'opérations élémentaires.
La complexité d'un tri par insertion s'exprime par O(n²) dans le pire cas.
La formule de la complexité d'une recherche binaire est donnée par O(log n).
La complexité d'un parcours de tableau est donnée par O(n), n étant la taille du tableau.

II. Théorèmes fondamentaux
Le théorème maître stipule que la complexité d'un algorithme diviser-pour-régner
se calcule selon la relation T(n) = aT(n/b) + f(n).
La loi de Moore exprime que le nombre de transistors double environ tous les deux ans.
La règle de la somme est donnée par O(f(n) + g(n)) = O(max(f(n), g(n))).

Pattern 15 — Chiffres / Statistiques

Marqueurs : représente N%, atteint N, mesure N, compte N, soit N sur

Cours : Sécurité Informatique — Données Clés

I. Statistiques sur les cyberattaques
Les cyberattaques représentent 43% des incidents signalés dans les entreprises en 2023.
Le coût moyen d'une violation de données atteint 4,5 millions de dollars par incident.
Le temps moyen de détection d'une intrusion mesure 207 jours selon les études récentes.
Le nombre de logiciels malveillants recensés dépasse 1 milliard de variantes connues.

II. Données sur les mots de passe
Un mot de passe de 6 caractères numériques compte seulement 1 million de combinaisons possibles.
Un mot de passe de 12 caractères alphanumériques représente plus de 3 000 milliards de combinaisons.
Les attaques par force brute atteignent un taux de succès de 80% sur les mots de passe courts.

Pattern 16 — Localisation

Marqueurs : se situe, se trouve, est localisé, dans le, au nord/sud/est/ouest de, s'étend sur

Cours : Architecture des Réseaux

I. Localisation des composants réseau
Le routeur se situe à la frontière entre le réseau local et Internet.
Le serveur DNS se trouve généralement dans la zone démilitarisée (DMZ) du réseau.
Le pare-feu est localisé entre le réseau interne et le réseau externe.
Le point d'accès WiFi se trouve dans la couche d'accès du réseau local.

II. Topologies et emplacements
Dans une architecture en étoile, le commutateur central se situe au cœur du réseau.
Le serveur de base de données est localisé dans le réseau interne, protégé des accès directs.
Le proxy inverse se trouve entre les clients Internet et les serveurs applicatifs internes.
La zone DMZ s'étend entre le pare-feu externe et le pare-feu interne.

Pattern 17 — Composition / Structure

Marqueurs : est composé de, comprend, contient, se compose de, est constitué de, inclut, regroupe, est formé de

Cours : Structure d'un Programme en C

I. Composition d'un fichier source
Un programme en C est composé d'une ou plusieurs fonctions.
Le fichier source comprend les directives d'inclusion, les déclarations et les fonctions.
Une fonction est constituée d'un en-tête et d'un corps délimité par des accolades.
L'en-tête d'une fonction contient le type de retour, le nom et les paramètres.

II. Structure d'un algorithme
Un algorithme se compose de trois parties : les données, le traitement et les résultats.
La partie déclaration regroupe toutes les variables et constantes utilisées.
Le corps de l'algorithme inclut les instructions de traitement dans l'ordre d'exécution.
Une structure conditionnelle est formée d'une condition, d'un bloc ALORS et d'un bloc SINON.

Pattern 18 — Synonymes

Marqueurs : aussi appelé, également nommé, autrement dit, c'est-à-dire, alias, synonyme de

Cours : Vocabulaire de la Programmation Orientée Objet

I. Synonymes des concepts objets
Une classe est aussi appelée type abstrait de données dans certains contextes.
La méthode est également nommée fonction membre ou comportement de l'objet.
L'attribut, autrement dit la propriété, représente les données d'un objet.
L'héritage, c'est-à-dire la relation "est-un", permet de créer des classes dérivées.

II. Autres termes équivalents
L'instance, alias l'objet, est une réalisation concrète d'une classe.
Le constructeur est également nommé initialiseur dans certains langages.
L'encapsulation, synonyme de masquage de l'information, protège les données internes.
Le polymorphisme, autrement dit la capacité d'un objet à prendre plusieurs formes.

Pattern 19 — Exceptions

Marqueurs : sauf, excepté, à l'exception de, hormis, attention, ne s'applique pas à, cas particulier, il faut noter que

Cours : Les Règles de Typage en Python

I. Règles générales et exceptions
En Python, toutes les variables sont typées dynamiquement, sauf les constantes définies par convention.
Les opérateurs arithmétiques s'appliquent aux entiers et aux réels, à l'exception de la division entière //.
Il faut noter que l'opérateur + fonctionne aussi sur les chaînes, ce qui constitue un cas particulier.
Les variables locales ne sont pas accessibles hors de leur fonction, hormis avec le mot-clé global.

II. Cas particuliers à retenir
Attention : la division de deux entiers en Python 3 retourne toujours un réel.
L'indentation est obligatoire pour tous les blocs, sauf pour les instructions d'une seule ligne.
Il faut noter que None n'est pas équivalent à False, même si les deux sont faux dans un test.
Les listes sont modifiables, à l'exception des tuples qui sont immuables.

Pattern 20 — Objectifs / Finalités

Marqueurs : a pour objectif, vise à, dans le but de, afin de, l'enjeu est de, cherche à

Cours : Introduction aux Bases de Données

I. Objectifs d'un système de gestion de bases de données
Un SGBD a pour objectif principal de stocker et organiser de grandes quantités de données.
Il vise à garantir l'intégrité et la cohérence des données à tout moment.
Le système de gestion cherche à permettre l'accès simultané à plusieurs utilisateurs.
L'indexation a pour objectif d'accélérer les recherches dans des tables volumineuses.

II. Finalités de la normalisation
La normalisation vise à éliminer les redondances dans la structure des tables.
Elle a pour objectif de réduire les anomalies lors des insertions, modifications et suppressions.
Les formes normales cherchent à garantir l'indépendance des données entre elles.
La troisième forme normale a pour objectif d'éliminer toutes les dépendances transitives.
La normalisation vise à rendre la base de données plus flexible face aux évolutions futures.
